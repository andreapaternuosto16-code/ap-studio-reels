## Rules for every reel
- Something changes every 1–2 s (cut, camera move, reveal, pop, object flying in). Open on motion + the hook in the first second. But hold each line long enough to read (reviewer timings).
- 1080×1920, 30 fps. Readable muted; text out of the top 220 px and bottom 380 px. Brand: Bricolage Grotesque / Figtree, deep teal #1F4F5B, teal #296675, cream #FFF7F4, blush #FADBD2. No glows/halos behind text; phone UI elements are allowed as real UI objects.
- Beat-synced to a royalty-free track (source noted), plus a no-music export.
